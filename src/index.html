🪄 새 DB 만들기

    jple 사용 방법

    1. 처음 설정: 설치하고 처음 켜면 연결할 DB를 물어요. 관리자에게 받은 연결 코드(jple-연결:로 시작)를 붙여 넣어요. 회사에서 처음 쓰는 관리자 1명만 새 DB 만들기를 해요.
    2. 아이디와 비밀번호: 연결 코드는 DB만 정해 줘요. 아이디와 처음 비밀번호는 관리자가 계정을 만들어 따로 알려 줘요. 관리자 아이디는 admin, 비밀번호는 새 DB 만들기 6단계에서 정한 것이에요.
    3. 로그인: 위쪽 🔑 로그인을 누르고, 받은 아이디와 처음 비밀번호를 넣어요. 비밀번호를 잊으면 관리자가 계정 목록에서 비밀번호 초기화를 해 줘요.
    4. 처음 비밀번호 바꾸기: 처음 로그인하면 새 비밀번호(8자 이상)를 두 번 넣어 바꿔요. 나중에는 ⚙ → 개인 설정 → 비밀번호 바꾸기.
    5. 일정 넣기: 위쪽 + 일정을 누르거나, 왼쪽 시간 줄의 빈 곳이나 +를 눌러요. 구분, 제목, 날짜, 시각, 장소를 적고 저장해요.
    6. 하루 일정 보기: 달력의 날짜 칸을 누르면 그날 일정이 한 줄씩 떠요. 왼쪽 내 업무와 학교 전체도 그날로 바뀌어요.
    7. 고치기·지우기: 일정을 눌러 고치거나 지워요. 다른 사람 일정은 볼 수만 있어요(관리자는 모두 고칠 수 있어요).
    8. 주간업무 표: 위쪽 스위치를 켜면 주간업무 표로 바뀌어요. 빈 칸을 누르면 그 부서, 그 날짜로 입력돼요.
    9. 인쇄·엑셀: 주간업무 표의 [인쇄]는 A4 가로 한 장, [엑셀]은 엑셀 파일로 저장해요.
    10. 알림: 다른 사람이 일정을 넣거나 고치거나 지우면 화면 오른쪽 아래에 알림이 떠요. ⚙ → 개인 설정에서 고를 수 있어요.
    11. 숨기기와 끄기: ✕는 숨기기예요. 시계 옆 아이콘을 누르면 다시 나타나요. 완전히 끄려면 그 아이콘을 오른쪽 클릭 → 완전히 종료.
    12. 로컬 서버: 인터넷 DB 대신 학교 안 PC 1대에 일정을 모을 수 있어요. 처음 설정에서 이 PC를 서버로 시작을 고르고 관리자 비밀번호를 정해요. 서버 PC는 늘 켜 두고, 직원들에게 DB 관리의 연결 코드를 보내요.
    13. 대기 서버: 로컬 서버가 꺼질 때를 대비해 PC를 1~2대 더 둘 수 있어요(없어도 돼요). 관리자가 DB 관리 → 서버 구성의 "지금 jple에 로그인해 있는 PC" 목록에서 PC를 골라 대기 1로/대기 2로를 누르면, 그 PC에 확인 창이 떠요. 그 PC에서 수락하면 대기 서버가 돼요. 주 서버가 꺼지면 몇 초 안에 대기 서버가 대신 일하고, 주 서버가 켜지면 저절로 돌아와요.
    14. 서버 PC 관리: 서버 PC(주·대기)는 jple이 절전을 막아 줘요. 다만 윈도우에 로그인해야 jple이 켜지니, 정전 뒤에도 서버가 켜지게 하려면 윈도우 자동 로그인을 켜 두세요(윈도우 키 + R → netplwiz → "사용자 이름과 암호를 입력해야…" 체크 해제). 서버 PC의 주소는 가능하면 전산 담당께 고정해 달라고 부탁하세요.
    15. 업데이트: 관리자가 새 버전을 자기 PC에 설치한 뒤 DB 관리 → 업데이트 배포에서 설치 파일을 고르면, 다른 PC들은 받아 두었다가 다음에 jple을 켤 때 저절로 바뀌어요. 바로 바꾸려면 시계 옆 아이콘 → "지금 업데이트".
    16. 로그인과 보안: 로컬 서버는 90일 동안 안 쓰면 로그인이 풀리고, 비밀번호를 5번 연속 틀리면 5분 동안 막혀요. 관리자가 비밀번호를 초기화하면 그 사람은 다시 로그인해야 해요. 학교 안 통신은 https로 암호화돼요.
    17. 다른 DB로 옮기기: 옮기기 전 DB의 DB 관리에서 옮기기 파일 만들기 → 옮길 DB의 DB 관리에서 옮기기 파일 가져오기. 모두 쓰던 비밀번호 그대로 로그인해요. 직원들은 ⚙ → 개인 설정 → 🔗 연결 바꾸기에 새 연결 코드를 넣어요.
    18. 꾸미기: ⚙ → 개인 설정에서 배경 진하기와 색 테마를 바꿔요. 위쪽을 끌어 옮기고, 오른쪽 아래 모서리를 끌어 크기를 바꿔요.
